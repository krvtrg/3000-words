# 3000 слов — английский каждый день

Два варианта одного и того же приложения, выбирайте любой:

- **`3000-words-setup.exe`** — программа для Windows 10 и 11: ярлык на рабочем столе, отдельное окно.
- **`english-words.html`** — файл, который открывается в любом браузере, на компьютере и на телефоне.

Регистрация не нужна. Заниматься можно без интернета; интернет нужен только для того,
чтобы приложение само получало новые версии.

## Как идут занятия

- **Сортировка** («Знаю» / «Учить») только отбирает слова: знакомые уходят из уроков, остальные
  встают в очередь. Сами слова при этом ещё не учатся.
- **Урок** берёт слова из очереди — по 10 в день, число меняется в настройках. После урока слово
  считается «в изучении» и приходит на повторение через 1, 3, 7, 14, 30 и 60 дней.
- **Статистика** считает уроки, повторения и тренировку. Сортировка показана в ней отдельно:
  строкой «Разобрано в сортировке» и клеткой с рамкой в календаре. Серию дней она не продлевает.
- **Учебный день длится до 4 утра.** Занятие после полуночи засчитывается за прошедший день;
  в это время в шапке стоит его дата с пометкой «до 4 утра».

## Программа для Windows

**Установка**

1. Скачайте `3000-words-setup.exe` и запустите.
2. Windows может показать синее окно «Система Windows защитила ваш компьютер»: у установщика
   нет платной цифровой подписи. Нажмите «Подробнее» → «Выполнить в любом случае».
3. «Установить» → «Готово». Ярлык «3000 слов» появится на рабочем столе и в меню «Пуск».

Права администратора не нужны. Своего браузера внутри программы нет: она открывает приложение
отдельным окном через Microsoft Edge, который есть в каждой Windows 10 и 11 (если Edge нет —
через Google Chrome). Поэтому установщик весит 0,3 МБ.

Если у вас стоит версия 1.2 или старше, установите новую поверх один раз вручную: закройте
программу и запустите новый `3000-words-setup.exe`. Прогресс останется на месте. Дальше
программа обновляется сама.

**Обновление — само, с версии 1.3**

- При запуске программа сразу открывает ту версию, что уже есть, и в фоне спрашивает у GitHub,
  не вышла ли новая. Новая версия скачивается, сверяется по контрольной сумме и включается
  при следующем запуске. Появится заметка «Приложение обновлено до версии …».
- Перед первым запуском новой версии программа делает копию прогресса. Если новая версия
  не запустилась, программа сама возвращает предыдущую.
- Без интернета всё работает как обычно, просто без обновлений.
- Новая версия доходит до программы не мгновенно: после публикации до 5 минут.

Всё управление — в приложении: Настройки → «Версия и обновления».

| Что там есть | Зачем |
|---|---|
| «Обновлять автоматически» | Выключите, если хотите обновляться только по кнопке |
| «Проверить сейчас» | Не ждать следующего запуска |
| «Все версии» → «Перейти» | Открыть любую выпущенную версию, от 1.0 до последней. Прогресс общий. Список свёрнут и раскрывается по нажатию |
| «Вернуться к последней» | Появляется, когда выбрана не последняя версия. Пока она выбрана, автообновление приостановлено |
| «Копии прогресса» | Копии, сделанные перед обновлением, сменой версии и сбросом. Любую можно восстановить |

В версиях 1.0–1.2 этого раздела ещё нет. Если перейти на одну из них, наверху окна будет
полоса с кнопкой «Вернуться к последней».

Новый установщик понадобится редко: только когда меняется сама программа, а не приложение
внутри неё. Тогда в разделе «Версия и обновления» появится сообщение со ссылкой.

**Перенос прогресса из `english-words.html`**

1. В браузере, где вы занимались: Настройки → «Сохранить прогресс» → «Скачать файл».
2. В программе на первом экране: «У меня уже есть сохранённый прогресс» → «Выбрать файл» → «Загрузить».
   Позже то же самое есть в Настройках: «Загрузить прогресс».

**Удаление**: Параметры Windows → Приложения → «3000 слов» → Удалить. Программа спросит,
удалять ли прогресс; по умолчанию он остаётся.

Где что лежит на компьютере: программа — `%LOCALAPPDATA%\Programs\Words3000`,
прогресс и скачанные версии — `%LOCALAPPDATA%\Words3000`.

## Файл для браузера

Откройте `english-words.html` в браузере. С версии 1.3 это тот же файл, что стоит внутри
программы, поэтому в браузере на компьютере он тоже обновляется сам и показывает раздел
«Версия и обновления». Скачивать новый файл не нужно.

Если браузер не даёт файлу хранить данные (так бывает на телефонах и в окнах предпросмотра),
файл работает как обычное приложение своей версии, без обновлений. На настоящем телефоне
это не проверялось.

Прогресс в браузере и прогресс в программе хранятся отдельно и переносятся файлом прогресса.

Отдельные версии без автообновления лежат в `versions/`: `english-words-v1.0.html` … `v1.4.html`.

## Что где лежит

| Путь | Что это |
|---|---|
| `3000-words-setup.exe` | Установщик программы для Windows, последняя версия |
| `english-words.html` | Программа: оболочка для автообновления со встроенной последней версией приложения. Её ставит установщик, её же можно открыть в браузере |
| `versions/` | Все версии приложения, установщики, `versions.json` (список версий, по которому программы обновляются) и `CHANGELOG.md` — что менялось |
| `dev/` | Всё служебное: исходники, сборка, тесты. Для учёбы не нужно |

Внутри `dev/`:

| Путь | Что это |
|---|---|
| `dev/src/app.js`, `app.css`, `template.html` | Логика, оформление, каркас страницы |
| `dev/src/build.py` | Сборка: версия приложения, список версий и файл программы |
| `dev/src/releases.json` | Дата и строка «что изменилось» для каждой версии; попадают в настройки приложения |
| `dev/src/data/words.json` | 3000 слов с переводами в том виде, как они в приложении |
| `dev/src/data/top_3000_words_translated.txt` | Ваш исходный список слов |
| `dev/src/data/translation-fixes.txt` | Какие переводы исходного списка исправлены вручную |
| `dev/tests/run.js` | Автотесты приложения (файл текущей версии из `versions/`) в Chromium, Firefox и WebKit |
| `dev/windows/launcher.nsi`, `installer.nsi`, `icon.ico` | Запускалка, установщик и значок программы |
| `dev/windows/build.py` | Сборка установщика |
| `dev/windows/check-installer.sh` | Проверка установки, обновления и удаления в эмуляторе Windows (Wine) |
| `dev/windows/appmode-test.js` | Проверка окна программы и сохранности прогресса |
| `dev/shell/shell.js`, `shell.html`, `build.py` | Оболочка: запускает выбранную версию, скачивает новые, делает копии прогресса, откатывает неудачную версию |
| `dev/shell/test.js` | Проверки оболочки на подставном сервере: обновление, откат, выбор версии, защита хранилища, файл программы из корня |
| `dev/shell/live.js` | Проба на настоящем GitHub: программа со старой версией сама получает последнюю. Только читает репозиторий |
| `dev/shell/soak.js` | Длинная проверка: сотни запусков подряд, прогресс должен быть виден каждый раз |

## Для изменений

Как выпустить новую версию приложения:

1. Поднять `VERSION` в `dev/src/build.py` и добавить запись в `dev/src/releases.json`.
2. Собрать и проверить (команды ниже).
3. Закоммитить и отправить в ветку `main` на GitHub. С этого момента программы получат версию
   сами. Отправка в `main` и есть выпуск: недоделанную версию туда не отправлять.

Новый установщик нужен, только если менялась оболочка (`SHELL` в `dev/shell/build.py`).

```
cd dev/src     && python3 build.py    # версия приложения, versions.json и файл программы
python3 build.py --check              # ничего не пишет: сверяет файлы на диске со сборкой
cd ../tests    && npm install && npx playwright install chromium firefox webkit
node run.js                           # все проверки приложения, около 11 минут
cd ../shell    && xvfb-run -a node test.js                                   # оболочка, около 5 минут
cd ../windows  && python3 build.py    # установщик; нужен NSIS (sudo apt install nsis)
./check-installer.sh && xvfb-run -a node appmode-test.js                     # около минуты
cd ../shell    && xvfb-run -a node live.js                                   # после отправки: проба на настоящем GitHub
```
