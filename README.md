# 3000 слов — английский каждый день

Два варианта одного и того же приложения, выбирайте любой:

- **`3000-words-setup.exe`** — программа для Windows 10 и 11: ярлык на рабочем столе, отдельное окно.
- **`english-words.html`** — файл, который открывается в любом браузере, на компьютере и на телефоне.

Интернет и регистрация не нужны ни там, ни там.

## Программа для Windows

**Установка**

1. Скачайте `3000-words-setup.exe` и запустите.
2. Windows может показать синее окно «Система Windows защитила ваш компьютер»: у установщика
   нет платной цифровой подписи. Нажмите «Подробнее» → «Выполнить в любом случае».
3. «Установить» → «Готово». Ярлык «3000 слов» появится на рабочем столе и в меню «Пуск».

Права администратора не нужны. Своего браузера внутри программы нет: она открывает приложение
отдельным окном через Microsoft Edge, который есть в каждой Windows 10 и 11 (если Edge нет —
через Google Chrome). Поэтому установщик весит 0,3 МБ.

**Перенос прогресса из `english-words.html`**

1. В браузере, где вы занимались: Настройки → «Сохранить прогресс» → «Скачать файл».
2. В программе на первом экране: «У меня уже есть сохранённый прогресс» → «Выбрать файл» → «Загрузить».
   Позже то же самое есть в Настройках: «Загрузить прогресс».

**Обновление**

1. Закройте программу.
2. Запустите новый `3000-words-setup.exe` — он установится поверх старого. Прогресс остаётся на месте.

Номер установленной версии — внизу экрана «Настройки». Сама программа обновления не ищет:
новую версию нужно скачать. На всякий случай перед обновлением сохраните прогресс в файл.

**Удаление**: Параметры Windows → Приложения → «3000 слов» → Удалить. Программа спросит,
удалять ли прогресс; по умолчанию он остаётся.

Где что лежит на компьютере: программа — `%LOCALAPPDATA%\Programs\Words3000`,
прогресс — `%LOCALAPPDATA%\Words3000`.

## Файл для браузера

Откройте `english-words.html` в браузере. Чтобы перейти на новую версию: в старой
Настройки → «Сохранить прогресс», открыть новый файл, Настройки → «Загрузить прогресс».
Прогресс в браузере и прогресс в программе хранятся отдельно и переносятся этим же файлом.

## Что где лежит

| Путь | Что это |
|---|---|
| `3000-words-setup.exe` | Установщик программы для Windows, последняя версия |
| `english-words.html` | Приложение для браузера, последняя версия |
| `versions/` | Копии всех версий и `CHANGELOG.md` — что менялось |
| `dev/` | Всё служебное: исходники, сборка, тесты. Для учёбы не нужно |

Внутри `dev/`:

| Путь | Что это |
|---|---|
| `dev/src/app.js`, `app.css`, `template.html` | Логика, оформление, каркас страницы |
| `dev/src/build.py` | Сборка приложения в один файл |
| `dev/src/data/words.json` | 3000 слов с переводами в том виде, как они в приложении |
| `dev/src/data/top_3000_words_translated.txt` | Ваш исходный список слов |
| `dev/src/data/translation-fixes.txt` | Какие переводы исходного списка исправлены вручную |
| `dev/tests/run.js` | Автотесты приложения в Chromium, Firefox и WebKit |
| `dev/windows/launcher.nsi`, `installer.nsi`, `icon.ico` | Запускалка, установщик и значок программы |
| `dev/windows/build.py` | Сборка установщика |
| `dev/windows/check-installer.sh` | Проверка установки, обновления и удаления в эмуляторе Windows (Wine) |
| `dev/windows/appmode-test.js` | Проверка окна программы и сохранности прогресса |

## Для изменений

```
cd dev/src     && python3 build.py    # перед изменениями поднять VERSION в build.py
cd dev/windows && python3 build.py    # установщик; нужен NSIS (sudo apt install nsis)
cd dev/tests   && npm install && npx playwright install chromium firefox webkit
node run.js                           # все проверки приложения, около 11 минут
cd ../windows  && ./check-installer.sh && xvfb-run -a node appmode-test.js   # около минуты
```
