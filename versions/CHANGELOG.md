# Версии приложения «3000 слов»

Актуальная версия всегда лежит в корне: `english-words.html` и `3000-words-setup.exe`.
В этой папке — копии каждой версии, чтобы можно было вернуться к любой.

Прогресс у всех версий хранится в одном формате. Перед переходом на другую
версию сохраните его: Настройки → «Сохранить прогресс».

## 1.2 — 15.11.2026
Появилась программа для Windows. Упражнения, расписание и формат прогресса не менялись.

Программа для Windows
- `3000-words-setup.exe` — установщик (0,3 МБ) для Windows 10 и 11. Ставится без прав
  администратора, добавляет ярлык на рабочий стол и в меню «Пуск», удаляется через
  «Приложения» Windows.
- Приложение открывается отдельным окном без адресной строки, через Microsoft Edge
  (если его нет — через Google Chrome). Работает без интернета.
- Обновление: новый установщик ставится поверх старого, прогресс при этом не затрагивается.
- Установщик каждой версии хранится в этой папке: `3000-words-setup-<версия>.exe`.

Приложение
- На первом экране появилась ссылка «У меня уже есть сохранённый прогресс» — файл прогресса
  можно загрузить сразу, не проходя первый урок. Так прогресс переносится из браузера в программу.
- Браузер больше не предлагает перевести страницу.

Служебное
- В `dev/windows/` — исходники запускалки и установщика, сборка и две проверки:
  установка, обновление и удаление в эмуляторе Windows; окно программы и сохранность прогресса.

## 1.1 — 15.11.2026
Исправления по итогам полной проверки. Новых разделов нет, формат прогресса тот же.

Управление
- Двойное касание «Дальше» больше не отвечает наугад на следующее задание, а двойное
  касание варианта не пролистывает показ правильного ответа.
- Зажатая клавиша (Enter, стрелки) не пролистывает задания и не сортирует слова пачкой.
- Enter и пробел на кнопке, выбранной клавишей Tab, нажимают именно её
  (раньше Enter на «Уже знаю это слово» просто вёл дальше).
- Прерванный системой свайп в сортировке больше не засчитывается.

Занятия
- Счётчик «ещё N» не подпрыгивает после ошибки.
- Если список закончился прямо во время отбора слов для урока, урок начинается с
  отобранными словами (раньше они оставались без урока до следующего захода).
- Ввод: принимаются `programme`, `practise` и слова с дефисом, набранные через пробел
  или слитно (`long term`, `oldfashioned`).
- Тренировка «На слух» при выключенном звуке больше не создаёт задания без звука.

Озвучка
- В задании на слух появилась кнопка «Нет звука» — слово показывается текстом.
- Если синтез речи на устройстве не работает (ошибка или тишина дольше 4 секунд),
  задания на слух сами заменяются выбором перевода; в настройках об этом написано.
- Очередь речи больше не сбрасывается без нужды: в части браузеров такой сброс
  глушит следующее слово (мера предосторожности, без звука здесь не проверить).

Дата и данные
- Граница суток 4:00 считается по местным часам и в день перевода часов.
- Вкладка, открытая с вечера, сама обновляет план после 4:00.
- Имя файла прогресса берётся по местной дате, а не по Гринвичу.
- Загрузка прогресса строже отбрасывает испорченные значения.

Оформление
- На узких экранах (320 px) длинная серия дней больше не раздвигает страницу.
- Длинные уведомления не сжимаются в узкий столбик и висят дольше.
- Подсветка «под курсором» не залипает на сенсорных экранах.
- Отступы под вырез экрана, запасные цвета для старых браузеров.
- Понятные подписи переключателей для экранного диктора, фокус переходит в открытое окно.

Размер файла: 189 → 180 КБ (словарь упакован компактнее).

Служебное (в самом приложении не видно)
- Автотесты в `dev/tests/run.js`: Chromium, Firefox, WebKit.
- Сборка отказывается перезаписывать уже выпущенную версию.
